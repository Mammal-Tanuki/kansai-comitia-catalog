# 関西コミティア77 個人Webカタログ

https://mammal-tanuki.github.io/kansai-comitia-catalog/

「会場マップ」で、サークル一覧で設定した色を公式配置図に重ねて表示します。
配置番号ボタンから該当区画へ移動でき、区画のタップでリンク・色・訪問済み・購入予定などを確認できます。
色と訪問済みは一覧と共通で、訪問済みには白い✓を表示します。灰色の区画もタップできます。
表示する色の切り替え、＋／−での拡大縮小、大展示場A〜N・1階O／Pの切り替えに対応しています。
一度オンラインで読み込んだ後は、配置図もオフラインで利用できます。
設定は端末内に保存され、バックアップ読込とカタログ更新でも保持します。

配置図は[公式サークル参加案内書の10ページ](https://www.k-comitia.com/pdf/77csanka.pdf#page=10)を出典とします。
全1,442掲載件の区画を照合しています。図には番号があっても公式サークル一覧にはない8区画へは、サークルを割り当てていません。
背景は公式図の切り出しで、当日の変更は現地・主催案内をご確認ください。

配置図の再生成：`python3 scripts/build_venue_map.py /path/to/77csanka.pdf`（PyMuPDFが必要）。
公開する画像・座標には個人の色・メモ・訪問済みを含めません。

検証：`node --test tests/*.test.cjs`、`python3 -m unittest discover -s tests -p 'test_*.py'`。
